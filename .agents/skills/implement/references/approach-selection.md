# Approach selection

Use this reference only for an unresolved material choice or a requested
comparison. A settled approach proceeds directly after its current-evidence
check. Use the issue requirements or provisional idea mini-spec as the outcome;
do not let a preferred mechanism redefine it.

- Assemble one neutral evidence packet from the repository, reproduction,
  project contracts, and shared current-state artifacts. Include current web
  research when a decision depends on external facts, as required by the
  implementation workflow. Derive every option from this same packet.
- Define one comparison rubric from the outcome, constraints, and measures of
  success before scoring. Give every viable option equivalent
  decision-relevant validation: show materially different UI experiences or
  architecture flows, and use comparable disposable prototypes or measurements
  when static evidence cannot resolve a technical claim. Equivalent checks do
  not require equal implementation effort. Label observed facts, proposed
  behavior, and prototype-only shortcuts.
- If an option exposes an evidence gap, apply the relevant check to every
  affected option. When that is impossible, disclose unequal evidence and reduce
  confidence before comparing.
- Keep prototypes local and disposable; retain only reviewable captures and
  findings, then remove prototypes when the grill concludes. Do not deploy or
  publish them. Preserve or promote one only with explicit approval, outside
  the selected worktree until its synchronization gate passes.
- Compare the distinct viable options that could change the decision against
  the declared rubric. Do not invent alternatives to fill a count.
  Compare first; recommend only afterward. Present the options, pros, cons,
  scores, uncertainties, checked versions, and source links in conversation.
  Use a table, diagram, or mockup only where it clarifies the decision.
- Do not select an option until the shared packet, predeclared rubric, and
  equivalent checks are complete. An incomplete comparison must name the gap
  and its confidence impact rather than treating an initial preference as
  validated.

Outside automatic mode, require the registered `grilling` skill and use its
actual decision loop, one decision at a time. Stop if it is unavailable; do not
imitate it with ad-hoc questions. Use the comparison and evidence above, then
wait for the user's choice. For an idea, confirm the final mini-spec covering
the outcome, scope/non-goals, and testable success measures. Automatic mode
selects the evidence-backed recommendation without this interview, while
preserving the same evidence and material-decision gates.
